# راه‌اندازی ربات و کانال بله برای VibeLab

## هدف
ربات بله باید مثل ربات تلگرام، مسیر آموزشی را داخل خود چت جلو ببرد:

- منوی کوتاه و واضح
- تحلیل رزومه/معرفی کوتاه داخل چت
- پیشنهاد مسیر آموزشی، مربی و نقطه آموزشی
- معرفی مدرسه اسنپی
- پست خودکار در کانال بله

---

## منوی پیشنهادی ربات بله

```txt
مسیر شغلی
تحلیل رزومه
کارآموزی
مدرسه اسنپی
موسیقی AI
کانال آموزش
```

## دستورها

```txt
/start       شروع و منو
/menu        نمایش منو
/learning    تحلیل رزومه و مسیر آموزش
/internship  کارآموزی طراحی سایت و محتوا
/school      مدرسه اسنپی دانش‌آموز و مربی
/masir       مسیر شغلی از رزومه تا پروژه
/music       موسیقی AI
/health      وضعیت سایت
```

---

## متن معرفی ربات بله

```txt
سلام 👋
من ربات VibeLab هستم.
اینجا می‌توانی رزومه یا معرفی کوتاهت را بفرستی تا مسیر آموزشی، نقطه نزدیک، مربی مناسب و برنامه دو روزه پیشنهادی بگیری.

برای شروع یکی از گزینه‌ها را انتخاب کن.
```

---

## برای گرفتن توکن بله چه کار باید کرد؟

1. وارد پیام‌رسان بله شوید.
2. ربات رسمی ساخت ربات / BotFather بله را باز کنید.
3. یک ربات جدید بسازید.
4. نام پیشنهادی:
   ```txt
   VibeLab Bot
   ```
5. username پیشنهادی:
   ```txt
   vibelab_bot
   ai_vibelab_bot
   masir_vibelab_bot
   ```
6. توکن ربات را دریافت کنید.
7. توکن را عمومی نفرستید. باید به شکل Cloudflare Secret ذخیره شود.

---

## Cloudflare Secretهای لازم

```bash
wrangler secret put BALE_BOT_TOKEN
wrangler secret put BALE_CHANNEL_ID
wrangler secret put BALE_CHANNEL_POST_SECRET
```

## Webhook پیشنهادی

```txt
https://v2.vibelab.ir/api/bale/webhook
```

## Channel post endpoint

```txt
https://v2.vibelab.ir/api/bale/channel-post
```

---

## وضعیت فعلی پروژه

در پروژه آماده شده:

- `/api/bale/webhook` آماده است.
- `/api/bale/channel-post` آماده است.
- جدول D1 برای لاگ پست‌های بله ساخته شده است.
- GitHub Action برای پست خودکار بله ساخته شده است.

هنوز لازم است:

- `BALE_BOT_TOKEN` داده شود.
- `BALE_CHANNEL_ID` داده شود.
- اگر API base بله متفاوت بود، مقدار `BALE_API_BASE` تنظیم شود.
