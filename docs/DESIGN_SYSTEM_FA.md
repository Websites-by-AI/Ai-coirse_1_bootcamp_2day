# سیستم طراحی VibeLab — فونت و رنگ

## هدف
طراحی باید برای مخاطب فارسی، آموزشی و بازار کار/نمونه‌کار قابل اعتماد باشد: مدرن، پرانرژی، خوانا و مناسب موبایل.

## تایپوگرافی

### فونت اصلی فارسی
```css
--font-fa: "Vazirmatn", "IRANSansX", "Dana", "Yekan Bakh", "Segoe UI", Tahoma, Arial, sans-serif;
```

پیشنهاد production: فونت Vazirmatn یا Yekan Bakh را self-host کنید تا همه کاربران یک تجربه ثابت داشته باشند.

### کاربرد
- تیترها: `--font-display`
- متن فارسی: `--font-fa`
- اعداد/ایمیل/لینک انگلیسی: `--font-latin` یا `dir="ltr"`

## تم‌ها
سایت چهار تم دارد:
- `light`: مناسب صفحه فروش و خوانایی
- `dark`: پیش‌فرض حرفه‌ای و AI
- `aurora`: تکنولوژی/آموزشی
- `rose`: خلاق و محتوایی

## قواعد طراحی
1. CTA اصلی همیشه از `--ds-primary` استفاده کند.
2. وضعیت دیتابیس/موفقیت با `--ds-success` نمایش داده شود.
3. هشدارهای غیر بحرانی زرد/نارنجی و خطاهای بحرانی قرمز باشند.
4. متن توضیحی کمتر از ۱۰px نشود مگر label خیلی کوچک باشد.
5. برای بازار ایران و رزومه، کارت‌ها باید روشن‌تر و خواناتر باشند؛ برای hero می‌توان dark/gradient نگه داشت.
6. پنل کاربر باید حس «مسیر کاریابی و نمونه‌کار» بدهد، نه فقط ابزار.
7. ادمین باید table-first و KPI-first باشد.

## وضعیت فعلی
- Design tokens به `src/app/globals.css` اضافه شده‌اند.
- پنل، ادمین، ثبت‌نام، آموزش و پروفایل از font stack مشترک استفاده می‌کنند.
- رنگ‌های اصلی landing به tokenهای semantic وصل شده‌اند.

## قدم بعدی پیشنهادی
- self-host کردن Vazirmatn در `/public/fonts`.
- ساخت کامپوننت‌های مشترک UI مثل `Button`, `Card`, `Badge`, `MetricCard`.
- کاهش font-sizeهای خیلی کوچک در پنل ادمین و موبایل.
